# prob_project — VARSA: Statistical Analysis of Indian Monsoon Rainfall Variability

## 🌧️ Website (Streamlit Dashboard)

The website is a Streamlit dashboard exploring IMD subdivision rainfall data:

- **File**: `app.py` — the full dashboard (6 interactive figures + controls)
- **Run**: `streamlit run app.py`
- **Data**: `data/raw/india_rainfall.csv` (generated by `scripts/data/generate_data.py`)

## 🔧 Getting Started

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Generate the rainfall dataset
bash scripts/fetch_data.sh

# 3. Start the dashboard
streamlit run app.py
```

The dashboard has 6 interactive figures:
1. **National Annual Rainfall** – time series of national mean (all divisions)
2. **Seasonal Rainfall by Division** – box plot for selected season
3. **Division-Level Time Series** – zoomable trend for selected divisions
4. **National Trend with Uncertainty** – linear trend + 95% CI
5. **Regional Ranking** – wettest/driest divisions
6. **CV by Division** – coefficient of variation (°more unpredictable)
