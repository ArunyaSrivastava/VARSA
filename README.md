# prob_project — VARSA: Statistical Analysis of Indian Monsoon Rainfall Variability

## 🌧️ Website (Streamlit Dashboard)

The website is a Streamlit dashboard exploring IMD subdivision rainfall data:

- **File**: `app.py` — the full dashboard (interactive WebGL map, **🏗️ 3D Rainfall-Height
  Atlas** with extruded subdivision prisms for 1901–2026, 3D globe, per-division
  statistical dossier, all-states comparison, key-takeaways fact sheet)
- **Run**: `streamlit run app.py`
- **Data**: `data/raw/india_rainfall.csv` (generated by `scripts/data/generate_data.py`)
  + the observed IMD layer (`scripts/data/fetch_observed.py`)
- **Prerequisites**: `python scripts/data/build_subdivision_geo.py` builds the
  subdivision boundaries used by the 3D atlas (requires `shapely`)
- **Rehaul blueprint**: `docs/website_rehaul.md` — phased plan for more 3D models,
  better India map visualizations and a flashier UI (Phase 1 shipped)

## 🔧 Getting Started

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Generate the rainfall dataset (seeded, deterministic)
bash scripts/fetch_data.sh

# 3. Run the full statistical pipeline (Review 3)
python scripts/final_analysis.py

# 4. Fetch + validate the observed post-2015 IMD layer (2015-2026)
python scripts/data/fetch_observed.py
python scripts/observed_analysis.py

# 5. Start the dashboard
streamlit run app.py
```

## 🆕 The observed post-2015 layer (the "missing decade", recovered)

`scripts/data/fetch_observed.py` downloads official IMD data — the **Annual Climate
Summary** subdivision tables (2015–2025) and the live **CMPG** all-India/region
tables (monthly + monsoon, 1901–**2026**) — parses three different PDF table layouts
(mirrored/transposed, normal, and a word-coordinate reconstruction for 2020), and
validates every cell against IMD's own printed % departure. The 2020 table is
auto-rejected by a quality gate (IMD "real time" values + broken text layer) rather
than shipped with silent errors. Highlights from the extended record
(`review_3/observed_results.json`):

- Null-trend verdict **confirmed on 125 years of observed data** (−18 mm/century, p = 0.50)
- 2016–2025 monsoon just +0.7% vs the 1901–2015 mean — no decade shift
- Live 2026 deficit: Jun–Sep 759 mm, **−12.6%** of normal
- Subdivision extremes: Kerala −34% (2016 *and* 2023); Saurashtra & Kutch +75% (2024)

## 📈 Headline findings (pipeline layer, 1901–2015)

1. **Monsoon dominance** — 73.7% of the national rainfall year arrives Jun–Sep
   (67.8–80.3% by division); season explains 51% of variance.
2. **Regions differ sharply** — region explains 86.1% of annual-rainfall variance
   (Welch ANOVA F(35,1445) = 588.5, p < 0.001); means span 148 mm (Ladakh) to
   3,511 mm (Konkan & Goa); CV spans 13.6% (Kerala) to 70.3% (Ladakh).
3. **Pooled totals are right-skewed** — KS distance: Normal 0.185 vs Gamma 0.094 vs
   Lognormal 0.069; within a division, annual totals are near-normal (33/36).
4. **No trend survives correction** — 3 of 36 raw p < 0.05 fall to 0 of 36 after
   Benjamini–Hochberg; national trend −34 mm/century, 95% CI [−117, +49].
5. **Drought risk is local** — a 1-in-20-year deficit reaches 15.8% of normal in
   West Rajasthan but only 77.8% in Kerala.
6. **Divisions share weather** — 64.9% of the 630 division pairs correlate
   significantly; 36 tests are not 36 independent samples.
