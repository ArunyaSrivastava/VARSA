## 2. Key Fields / Columns

**Reference layer (raw IMD, wide format):**

| Data type | Fields | Description |
|---|---|---|
| Identifiers | `SUBDIVISION`, `YEAR` | 36 met-subdivisions, 1901–2015 |
| Numeric (monthly) | `JAN` … `DEC` | monthly totals, mm |
| Numeric (seasonal) | `Jan-Feb`, `Mar-May`, `Jun-Sep`, `Oct-Dec` | seasonal totals, mm |
| Numeric (annual) | `ANNUAL` | annual total, mm |

**Pipeline layer (long format — analysed by the final pipeline):**

| Data type | Fields | Description |
|---|---|---|
| Temporal | `year` | 1901–2015 (int) |
| Categorical | `division` | 36 subdivisions |
| Categorical | `season` | `DJF`, `MAM`, `JAS` (Jun–Sep monsoon), `OND`, `ANNUAL` |
| Numeric | `rainfall_mm` | total for that division-year-season, mm |

---

## 6. Notes / Assumptions

- Aggregated subdivision data cannot support daily-extreme analyses.
- Subdivision boundaries changed over the century; IMD's 36-division scheme is treated as fixed.
- Pooled distributions mix wet and arid regions — distributional conclusions must state
  the unit of analysis (see Review 3, Figure 4 discussion).
- Assumption: each division-year is one observation; division series are cross-correlated
  (quantified in Review 3, Figure 7).
